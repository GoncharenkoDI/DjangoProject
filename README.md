Написати застосунок комп’ютерного тестування: 
Перша сторінка (форма) запитує користувача його ПІБ і є кнопка «Розпочати тестування»
Після натискання формуються і стають доступні користувачу сторінки з питаннями (до 5) та вибором однієї з 4 відповідей
Доступний перехід між питаннями (на формах є кнопки «Попереднє», «Наступне»)
Після того, як користувач на всіх формах обрав відповідь на кожній з’являється кнопка «Завершити тестування»
Після натискання кнопки «Завершити тестування» користувачу формується інформація про кількість балів, яку він набрав.
Питання, варіанти відповідей, правильні відповіді зберігаються в базі даних, яка відрізняється від SQLITE (наприклад MYSQL або PostgreSQL)
